## 项目说明
METstudio 是一个用于音乐综合听辨练习的智能软件，旨在帮助用户提高音乐听觉能力，通过系统化的训练和评估，实现对音高、节奏、和声等音乐要素的全面掌握。
### 功能介绍
- 音高训练：通过识别和模仿音高，提升音高辨识能力。
- 节奏训练：通过节奏模仿和打击练习，增强节奏感。
- 和声训练：通过和声分析和识别，提升和声理解能力。
- 系统评估：根据用户的训练表现，提供个性化的学习建议和进度跟踪。
- 多样化曲目：提供丰富的音乐曲目，涵盖不同风格和难度，满足多样化的训练需求。
- 用户社区：支持用户之间的交流与分享，促进学习经验的互相借鉴。
- 个性化设置：允许用户根据自身需求调整训练内容和难度，实现个性化学习体验。
- 数据统计与分析：记录用户的训练数据，提供可视化的统计和分析，帮助用户了解自己的学习进展。
- 多平台支持：软件可在多种操作系统和设备上运行，方便用户随时随地进行训练。
- 离线模式：支持离线使用，用户无需持续联网即可进行训练。
- 多语言支持：提供多种语言界面，方便不同语言背景的用户使用。
- 云端同步：支持用户数据在云端同步，保证多设备间的训练进度一致。
