# Music Ear Training (Music练耳软件)项目企划

## 文件夹结构

```
MusicEarTraining/
├── src/                # 源代码
|     ├── components/   # 组件
|     ├── utils/        # 工具函数
|     └── services/     # 服务层
├── assets/             # 资源文件（音频、图片等）
|     ├── audio/        # 音频采样
|     ├── images/       # 图片资源
|     └── fonts/        # 字体资源
├── tests/              # 测试代码
|     └── run.js        # 测试主文件
|
└── README.md           # 项目说明文件
```
## 项目说明
METstudio 是一个用于音乐综合听辨练习的智能软件，旨在帮助用户提高音乐听觉能力，通过系统化的训练和评估，实现对音高、节奏、和声等音乐要素的全面掌握。
